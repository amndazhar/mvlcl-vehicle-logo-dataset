# Examples

**This folder intentionally contains no real dataset images.**

The MVLCL images are frames of CCTV footage from a residential entrance. They were used with the data owner's permission for an academic project, and permission to redistribute them is not documented. Blurring plates and faces doesn't by itself make such images safe or permitted to publish; see [docs/privacy-and-ethics.md](../docs/privacy-and-ethics.md).

## What is available instead

| Need | Where |

| What an annotation looks like | [`visualizations/annotation-examples/yolo-annotation-format.png`](../visualizations/annotation-examples/yolo-annotation-format.png) (synthetic) |
| What the augmentations do | [`visualizations/preprocessing-examples/augmentation-geometry.png`](../visualizations/preprocessing-examples/augmentation-geometry.png) (synthetic) |
| What CLAHE does | [`visualizations/preprocessing-examples/clahe-synthetic-demo.png`](../visualizations/preprocessing-examples/clahe-synthetic-demo.png) (synthetic) |
| What anonymisation does | [`visualizations/preprocessing-examples/anonymisation-steps.png`](../visualizations/preprocessing-examples/anonymisation-steps.png) (synthetic) |
| Dataset statistics | [`analytics/`](../analytics/) (aggregate only) |

All synthetic figures are generated by [`visualizations/generate_synthetic_figures.py`](../visualizations/generate_synthetic_figures.py) from a drawn scene. The fake plate, timestamp and face are invented, and the emblem is a generic shape, not a real brand.

## If authorised sample images become available

Only add images that are covered by **written redistribution permission** from the data owner, have passed the full anonymisation pipeline **and** manual review, and contain no site-identifying content. Then:
1. Add the images to this folder.
2. Add a matching `!examples/*.jpg` exception to `.gitignore`.
3. State the permission in this README.
